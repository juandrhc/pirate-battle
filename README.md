# Pirate Battle

## 🇧🇷 Português

### Sobre o projeto

Pirate Battle é um jogo de combate naval 2D desenvolvido para o desafio técnico da Jungle Gaming, para a vaga de Frontend Game Developer.

Minha proposta foi construir uma experiência jogável, utilizando React, TypeScript e PixiJS, combinando minha experiência em design e front-end com os conhecimentos que venho adquirindo em programação e desenvolvimento de jogos.

### Tecnologias

React · TypeScript · PixiJS · Vite · CSS3 · LocalStorage · ESLint

### Funcionalidades implementadas

- Movimentação, rotação e disparos do navio.
- Inimigos Chaser e Shooter.
- Colisões, explosões, vida e pontuação.
- Partidas com duração configurável entre 60 e 180 segundos.
- Pausa manual, pausa automática e reinício.
- Menu principal e configurações salvas no navegador.
- Interface responsiva e controles mobile com suporte a multitouch.

### Controles

| Tecla | Ação |
|---|---|
| W / ↑ | Avançar |
| A / ← | Girar à esquerda |
| D / → | Girar à direita |
| Espaço | Disparo frontal |
| Q | Disparos à esquerda |
| E | Disparos à direita |
| Esc | Pausar / Retomar |

No mobile, os controles estão disponíveis na própria interface do jogo.

### Como executar

```bash
npm install
npm run dev
```

Build, verificação do código e visualização da versão de produção:

```bash
npm run build
npm run lint
npm run preview
```

### Considerações sobre a entrega

Minha experiência profissional está principalmente ligada ao design, ao desenvolvimento front-end e ao JavaScript. React, TypeScript e PixiJS fazem parte do meu atual processo de aprofundamento técnico.

Considerando o prazo do desafio e meu momento como desenvolvedor, decidi priorizar uma versão funcional, organizada e que eu pudesse compreender e explicar tecnicamente.

Utilizei inteligência artificial como ferramenta de apoio ao aprendizado, à implementação e à revisão do código, acompanhando o desenvolvimento, os testes e as correções.

Tenho consciência de que o projeto não contempla todos os requisitos solicitados. Prefiro apresentar com transparência o que consegui desenvolver e reconhecer os pontos nos quais ainda preciso evoluir.

### Requisitos pendentes

- Integração REST API com Axios.
- TanStack Query e MSW.
- Leaderboard funcional e histórico de partidas.
- Configuração do intervalo de surgimento dos inimigos.
- Testes automatizados com Playwright.

O build de produção e a verificação com ESLint foram concluídos sem erros.

Mais informações sobre a estrutura do código estão disponíveis em [ARCHITECTURE.md](./ARCHITECTURE.md).

## 🇺🇸 English

### About the project

Pirate Battle is a 2D naval combat game developed for Jungle Gaming's technical challenge for the Frontend Game Developer position.

My goal was to build a playable experience using React, TypeScript and PixiJS, combining my background in design and front-end development with my growing knowledge of programming and game development.

### Technologies

React · TypeScript · PixiJS · Vite · CSS3 · LocalStorage · ESLint

### Implemented features

- Ship movement, rotation and cannon attacks.
- Chaser and Shooter enemies.
- Collisions, explosions, health and scoring.
- Configurable match duration between 60 and 180 seconds.
- Manual pause, automatic pause and restart.
- Main menu and persistent browser settings.
- Responsive interface and mobile controls with multitouch support.

### Controls

| Key | Action |
|---|---|
| W / ↑ | Move forward |
| A / ← | Turn left |
| D / → | Turn right |
| Space | Fire front cannon |
| Q | Fire left cannons |
| E | Fire right cannons |
| Esc | Pause / Resume |

Mobile players can use the on-screen controls.

### Getting started

```bash
npm install
npm run dev
```

Build, lint and preview the production version:

```bash
npm run build
npm run lint
npm run preview
```

My professional background is mainly in design, front-end development and JavaScript. I am currently expanding my technical knowledge of React, TypeScript and PixiJS.

I used AI as a supporting tool for learning, implementation and code review, actively participating in development, testing and troubleshooting.

### Pending requirements
